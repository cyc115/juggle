### 2. Centralize label-to-thread resolution
**File: `src/juggle_db.py` (new method) + callers in `src/juggle_spool.py`, `src/juggle_cockpit.py`**

Three distinct callsites each independently implement "newest live thread wins on label collision." Extract a single method:

```python
def resolve_label(self, label: str) -> str | None:
    """Return the id of the active thread for label, newest-live-first. None if not found."""
    rows = self._query(
        "SELECT id FROM nodes WHERE user_label=? AND kind='conversation' "
        "ORDER BY CASE state WHEN 'open' THEN 0 WHEN 'running' THEN 1 "
        "WHEN 'background' THEN 2 ELSE 3 END, created_at DESC LIMIT 1",
        (label,)
    )
    return rows[0]["id"] if rows else None
```

Callers in spool and cockpit replace their local implementations with `db.resolve_label(label)`. This eliminates the class of bugs where a new callsite gets label resolution wrong, and makes the next label-collision fix a one-line change instead of a three-file audit.
